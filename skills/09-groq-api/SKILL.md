## 這一包完成後會涵蓋什麼

把「有聲音的東西」變成「可以編輯的文字」：上課錄音變逐字稿、教學影片自動上字幕。

預計會教：

- 申請 Groq 的存取金鑰，以及金鑰要放在哪裡才不會不小心上傳到 GitHub
- 呼叫 Whisper 模型，把音訊轉成含時間碼的 `.srt` 字幕檔
- 長檔案怎麼切、切完怎麼接，時間碼才不會跑掉
- 中文的常見狀況：簡繁、標點、專有名詞與人名的校訂
- 常見情境：教學影片上字幕、演講逐字稿、把上課錄音整理成講義草稿
- **隱私提醒**：語音會送到雲端處理。含學生聲音、家長談話、輔導或個案內容的錄音，一律不要上傳——這一段會寫在最前面。

**為什麼放在「API」這一階**：這是整套研習裡第一個「呼叫外部服務、拿回結果」的例子。學會這個模式，之後接別的服務就是同一套邏輯。

## 在此之前可以怎麼做

**① 平台內建的自動字幕（最快）**
影片上傳到 YouTube 後會自動生成字幕，可以下載下來再人工校訂。中文辨識不算完美，但當初稿夠用了。

**② 先把音軌抽出來備著**
**`02-file-toolkit`** 那一包含 yt-dlp 與 FFmpeg，可以先請 OpenCode 把影片的音軌抽成音訊檔、切成適當長度。等這一包寫好，素材直接就能用。

**③ 校訂交給 OpenCode**
不管字幕是哪裡來的，把 `.srt` 丟給 OpenCode，請它修錯字、統一專有名詞、調整斷句——**但要交代它不要改時間碼**，時間碼一動就對不上畫面了。

**④ 不要為了趕進度亂找工具**
網路上有很多「免費線上轉字幕」的網站。上傳前先想清楚那個檔案裡有沒有學生的聲音——這件事比省下的時間重要。
